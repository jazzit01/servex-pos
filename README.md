# ServeX POS 0.4.1 for Windows x64

Close ServeX before running the installer. It includes the .NET desktop
runtime. Existing data stays in Local App Data.

The app opens on Floor, where Indoor, Outdoor, and Rooms are grouped.
Open Orders to start a takeaway or resume unfinished work. Sales holds
completed transactions and reports. Managers can open Manage for menu,
table setup, and settings. On Floor, select Table actions and then a tile
to reserve a table, release a reservation, or mark it clean.

See SHA256SUMS.txt for the installer checksum.
