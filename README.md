# ServeX POS 0.3.9 for Windows x64

Close ServeX before running the installer. The installer includes the .NET
desktop runtime. Existing data stays in Local App Data.

Open Tables, select Indoor or Outdoor, and click Arrange tables. Drag a table
into an empty grid space or drop it onto another table to swap places. Each
move saves automatically. Select Done arranging to return to service.

See SHA256SUMS.txt for the installer checksum.
