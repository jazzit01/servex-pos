# ServeX POS 0.4.0 for Windows x64

Close ServeX before running the installer. It includes the .NET desktop
runtime. Existing data stays in Local App Data.

ServeX uses the Warm Bistro palette. In Tables, select Indoor or Outdoor,
click the pencil, drag tiles into position, then click Done. Right-click a
tile to manage its table. New table numbers use T1 indoors and OT1 outdoors.

See SHA256SUMS.txt for the installer checksum.
