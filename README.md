# ServeX POS 0.3.4 for Windows x64

Close ServeX before running `ServeX-0.3.4-win-x64-setup.exe`. This unsigned
installer includes the .NET desktop runtime. The database stays in Local App
Data.

The live clock now appears in the top header. When adding a table, numeric
entries receive the area prefix, such as IN-6 or OUT-6. Custom names are kept.

See `SHA256SUMS.txt` for the installer checksum. Interactive Windows
verification remains pending.
