# ServeX POS 0.3.7 for Windows x64

Close ServeX before running `ServeX-0.3.7-win-x64-setup.exe`. This unsigned
installer includes the .NET desktop runtime. The database stays in Local App
Data.

Unnamed parcel orders display as Parcel. New automatically generated table names
use I- indoors and O- outdoors. See `SHA256SUMS.txt` for the installer checksum.
Interactive Windows verification remains pending.
