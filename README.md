# ServeX POS 0.3.2 for Windows x64

Close ServeX before running `ServeX-0.3.2-win-x64-setup.exe`. This unsigned
installer includes the .NET desktop runtime. The database is stored separately
under `%LOCALAPPDATA%\ServeX`.

This version includes a collapsible sidebar, a remembered username option, a
live Dashboard clock, and clearer floor management. Fresh restaurant setup
automatically creates five indoor tables, five outdoor tables, and three rooms.
Existing installations keep their existing layout.

Check the SHA-256 value in `SHA256SUMS.txt`. The package payload was verified.
Interactive installation and UI behavior still need Windows verification.
