# ServeX POS 0.3.6 for Windows x64

Close ServeX before running `ServeX-0.3.6-win-x64-setup.exe`. This unsigned
installer includes the .NET desktop runtime. The database stays in Local App
Data.

The app uses sage and white as its main colors, with black text. Warning and
error indicators remain distinct. See `SHA256SUMS.txt` for the installer
checksum. Interactive Windows verification remains pending.
