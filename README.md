# ServeX POS 0.4.2 for Windows x64

Close ServeX before running the installer. It includes the .NET desktop
runtime. Existing data stays in Local App Data.

Select a table on the Floor to open its order in the right-side panel.
Search the menu and add items, change quantities, or remove items there.
Use Save order to keep changes or Cancel order to cancel the order.
Checkout opens the existing billing screen and returns to the floor.

See SHA256SUMS.txt for the installer checksum.
