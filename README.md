# ServeX POS 0.3.5 for Windows x64

Close ServeX before running `ServeX-0.3.5-win-x64-setup.exe`. This unsigned
installer includes the .NET desktop runtime. The database stays in Local App
Data.

The sidebar toggle now stays at the top left when the sidebar collapses. The
local date and time are displayed separately in a clock card at the top right.

See `SHA256SUMS.txt` for the installer checksum. Interactive Windows
verification remains pending.
