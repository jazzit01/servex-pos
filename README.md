# ServeX POS 0.3.8 for Windows x64

Close ServeX before running `ServeX-0.3.8-win-x64-setup.exe`. This unsigned
installer includes the .NET desktop runtime. The database stays in Local App
Data.

This build fixes rounding at checkout, separates totals by currency, adds a Resume parcel action in History,
uses room numbers on the dashboard, and provides clearer database startup
messages. See `SHA256SUMS.txt` for the installer checksum.

Interactive Windows verification remains pending.
