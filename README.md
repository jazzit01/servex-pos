# ServeX POS 0.3.3 for Windows x64

Close ServeX before running `ServeX-0.3.3-win-x64-setup.exe`. This unsigned
installer includes the .NET desktop runtime. The database stays in Local App
Data.

This update improves the sidebar toggle and selected state, button text contrast,
and the dashboard’s empty order lists. See `SHA256SUMS.txt` for the installer
checksum. Interactive Windows verification remains pending.
